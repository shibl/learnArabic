# Sindibad Letters · حروف سندباد

Part of [Sindibad Studios](https://sindibad.studio) — meaningful playful experiences in Arabic.

An app that helps children (4–10) of Arab families living outside the Arab world learn to read, speak and love Arabic.

**Live work tracker:** https://shibl.github.io/learnArabic/tracker/

| Folder | What's inside |
|---|---|
| `tracker/` | Live dashboard of all work (business, product, curriculum, design, engineering, marketing). Data in `tracker/data.json`. |
| `docs/` | Strategy: vision, market, competitors, business model, personas, go-to-market. |
| `curriculum/` | Learning path and content data. |
| `app/` | The web app (installable PWA). |
| `site/` | Marketing landing page. |

Updating the tracker: `python3 tracker/update.py log eng "message"` (see the script header for all commands).
