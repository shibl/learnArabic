# 07 · Brand basics (v0)

**Working name:** Huroof · حروف (final name pending — see tracker "Needs you").

**Guide character:** **Hudhud the hoopoe** (هُدْهُد). A bird found from Morocco to Iraq, recognisable crest, appears in stories across the Arab world — shared heritage, not tied to one country. Hudhud flies between the letter islands and cheers the child on.

**Feel:** warm, sunny, hand-made; never "babyish" for 8-year-olds. Big shapes, few words, lots of sound.

| Token | Colour | Use |
|---|---|---|
| Sand | `#fbf3e4` | background |
| Ink | `#2b2118` | text |
| Teal | `#0f8b8d` | primary / buttons |
| Coral | `#ef6f5c` | highlights, Hudhud's crest |
| Sun | `#f6b93b` | stars, rewards |
| Leaf | `#4caf6d` | correct |

**Type:** *Baloo Bhaijaan 2* (Google Fonts) — rounded, friendly, designed for both Arabic and Latin, so Arabic and English/French sit together naturally.

**Voice:** short, warm, encouraging, in the child's school language; Arabic always vowelled (with harakat) for learners.
